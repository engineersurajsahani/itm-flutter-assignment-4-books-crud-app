# 📱 Books CRUD Mobile / Web App (Flutter)

The frontend client for the **Books CRUD Full-Stack Application**, built with **Flutter 3**, **Dart 3**, and **Material 3**.

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
flutter pub get
```

### 2. Run the App

- **On Chrome (Web - Instant & No setup required)**:
  ```bash
  flutter run -d chrome
  ```

- **On macOS Desktop**:
  ```bash
  flutter run -d macos
  ```

- **On Connected Android Device or Emulator**:
  ```bash
  flutter run
  ```

---

## ⚙️ Backend Connection

By default, the app connects to the Node.js REST API on port `5050`:
- **Web / macOS / iOS Simulator**: `http://localhost:5050/api`
- **Android Emulator**: `http://10.0.2.2:5050/api`
- **Physical Device**: Tap the **⚙️ Settings icon** in the top bar to set your local IP address.
